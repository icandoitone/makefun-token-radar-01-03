The fitted model

The model is fitted on the protocols whose tokens already trade. It learns how the market prices a protocol from its TVL, its seven-day growth, how long it has run and how many chains it is on — then it prices the protocols that have not launched yet. No protocol name is ever special-cased: the same fit scores every row.

Tested out of sample

Leave-one-out: each traded protocol is held out in turn, the model is refitted without it, and the held-out market cap is predicted. The error below is what the model gets wrong on tokens it has never seen — the honest measure of the fit, not its in-sample score. The value range on every row comes from 200 bootstrap refits: resample the traded set, refit, predict again, and take the 10th–90th percentile.

The traded tokens are the anchors: the market's own prices, against the fitted value for the same protocol. A model that cannot price what already trades cannot price what has not launched yet.

How to read this radar

  1. Implied value is what the fitted model says the protocol's token would be worth at launch, given its TVL, growth, age and chains — priced off the traded comps.
  2. Value range is the 10th–90th percentile over 200 refits: a wide range means the model is unsure; a narrow one means the comps agree.
  3. Rank range is where the protocol would sit if its value were at either end of that range.
  4. Farm plan sizes the deposit by the protocol's TVL and states the gas and the time of every step. Thin means the plan costs more than the position is worth — skip it.
  5. The board covers every rankable pre-token protocol in the snapshot (198 of the 342 that record no token; exchanges, bridges, liquid-staking and restaked products, wrapped names, versioned pools and exchange-named protocols are set aside, as the snapshot's own watchlist rule does), not just the watchlist: the watchlist is the floor, never the ceiling.

What this radar does not do

It does not predict whether or when a token is issued. The implied value is this entry's own claim about what a launch would be worth if the protocol's record stayed as it is. A protocol the snapshot says records no token may still have one its DefiLlama record does not carry — so the board says a protocol records no token, never that it has none. Farm at your own risk; a claim that asks for a fee or a seed phrase is a scam.
